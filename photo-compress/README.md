# StudentDocs - Govt Exam Photo & Signature Compressor (Web Tool)

100% Client-Side, Privacy-Preserving Photo and Signature Image Resizer designed specifically for Indian competitive exams (SSC, UPSC, Railway, IBPS, NEET).

## Features
- **Precision Target KB Slider**: Set exact file size from 5 KB to 300 KB.
- **1-Click Official Presets**: Pre-configured buttons for SSC/UPSC Photo (20-50 KB), Signature (10-20 KB), and NEET (10-100 KB).
- **Before vs After Preview**: Real-time side-by-side comparison of original size, dimensions, and compressed result.
- **Binary Search Quantization**: Automatic bicubic scaling and JPEG compression curves for crystal-clear face clarity.
- **SEO & AI Search Ready**: Bundled with `sitemap.xml`, `robots.txt`, `llms.txt`, and Google JSON-LD schema.
