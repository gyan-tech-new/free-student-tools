# StudentDocs - Merge PDF Online (Web Tool)

100% Client-Side, Privacy-Preserving PDF Merger designed for students, educators, and job applicants.

## Features
- **Zero Server Uploads**: Native PDF stream stitching in local memory using `pdf-lib`.
- **Custom Sequencing**: Move files Up and Down to set perfect page and document order.
- **Fast & Unlimited**: Combine multiple PDFs without file size limits or paywalls.
- **SEO & AI Search Ready**: Bundled with `sitemap.xml`, `robots.txt`, `llms.txt`, and Google JSON-LD schema.
