# StudentDocs - Text to PDF Converter (Web Tool)

100% Client-Side, Privacy-Preserving Plain Text & TXT to PDF Converter designed for students, essayists, and academics.

## Features
- **Auto-Pagination**: Smart page calculation across consecutive A4 pages.
- **Custom Typography**: Helvetica, Times New Roman, and Courier font families with size, line-spacing, and margin controls.
- **Real-time Metrics**: Live word counter and character counter.
- **File Ingestion**: Direct type/paste or instant `.txt` file reader.
- **SEO & AI Search Ready**: Bundled with `sitemap.xml`, `robots.txt`, `llms.txt`, and Google JSON-LD schema.
