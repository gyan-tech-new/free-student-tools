# StudentDocs — Free Academic & Document Suite

A 100% client-side, zero-cost, high-privacy student & document utility suite.

## Included Tools
1. **Smart Scientific Math Calculator** (`/math-calculator/`)
2. **Exam Photo & Signature Compressor** (`/photo-compress/`)
3. **High-DPI PDF Compressor** (`/pdf-compress/`)
4. **Image to PDF Converter** (`/img2pdf/`)
5. **Merge PDF Documents** (`/merge-pdf/`)
6. **Text to PDF Generator** (`/text2pdf/`)

## Features
- **100% Client-Side**: No backend server, zero upload latency, 100% private.
- **Modern Responsive Design**: Built with Tailwind CSS.
- **Search Engine & AI Discovery Optimized**: Includes `sitemap.xml`, `robots.txt`, `llms.txt`, and Schema.org JSON-LD.
