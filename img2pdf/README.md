# StudentDocs - Image to PDF Converter (Web Tool)

100% Client-Side, Privacy-Focused Image to PDF Converter designed specifically for students, educators, and job applicants.

## Features
- **Zero Server Uploads**: Converts images inside client memory with jsPDF.
- **Orientation & Margin Controls**: Supports Portrait/Landscape and custom padding.
- **Page Manager**: Delete, inspect, and organize image pages.
- **SEO & AI Search Ready**: Bundled with `sitemap.xml`, `robots.txt`, `llms.txt`, and Google JSON-LD schema.
