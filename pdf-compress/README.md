# StudentDocs - PDF Compressor Online (Web Tool)

100% Client-Side, Privacy-Preserving PDF Size Reducer designed for college assignments, exam applications, and academic submissions.

## Features
- **3 Dynamic Compression Profiles**: Extreme (lowest size), Recommended (balanced), Light (sharp diagrams).
- **Client-Side Rendering Engine**: Uses PDF.js and jsPDF canvas re-quantization in local memory.
- **Zero Server Uploads**: Confidential marksheets and identity cards never touch external servers.
- **Real-Time Progress & Saved Stats**: Live progress bar and exact reduction metrics (% smaller).
- **SEO & AI Search Ready**: Bundled with `sitemap.xml`, `robots.txt`, `llms.txt`, and Google JSON-LD schema.
