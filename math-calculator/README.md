# StudentDocs - Smart Scientific Math Calculator (Web Tool)

An intuitive, modern online scientific math calculator inspired by CalcES (Casio fx-991ES Plus / ClassWiz) architecture, redesigned with an accessible, student-friendly interface.

## Highlights
- **Human-Friendly UI**: Replaces 50 cramped physical calculator buttons with clean, categorized functional tabs.
- **Full Scientific Engine**: Fractions, powers, nth-roots, trigonometry (Deg/Rad), logs, combinatorics, physical constants.
- **Specialized Math Solvers**: Quadratic equations, 2-variable systems, descriptive statistics, and numerical calculus.
- **Client-Side Speed**: 100% browser-based computation via MathJS.
- **SEO & AI Search Ready**: Bundled with `sitemap.xml`, `robots.txt`, `llms.txt`, and Google JSON-LD schema.
